JSON 格式化與驗證工具

貼上 JSON 字串即可即時縮排排版、壓縮成單行並檢查語法是否正確，全程於瀏覽器本機運算。

工具說明與常見 JSON 語法錯誤

JSON（JavaScript Object Notation）是 API 回傳與設定檔最常使用的輕量級資料交換格式。透過本工具可快速將擠成一行的 API 回應展開為易讀階層，或在送出請求前先壓縮體積並確認格式正確。

  • 多餘的尾隨逗號：最後一個屬性或陣列元素後方不能有逗號（例如 {"a": 1,} 會導致解析失敗）。
  • 引號格式錯誤：JSON 的鍵名（Key）與字串值必須使用雙引號 "，不能使用單引號 '。
  • 包含註解：標準 JSON 不支援 // 或 /* ... */ 註解語法。
