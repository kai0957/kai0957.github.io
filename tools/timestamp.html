什麼是 Unix 時間戳（Unix Timestamp）？

Unix 時間戳是指從協調世界時（UTC）1970 年 1 月 1 日 00:00:00 起至指定時間所經過的總秒數（或毫秒數）。由於不受時區與各國日期格式差異影響，常被廣泛用於資料庫紀錄、API Token 過期時間與系統日誌中。

  • 10 位數時間戳：單位為「秒」（Seconds），常見於 UNIX 系統、PHP、Python 與 JWT exp 欄位。
  • 13 位數時間戳：單位為「毫秒」（Milliseconds），常見於 JavaScript Date.now() 與 Java 系統。
