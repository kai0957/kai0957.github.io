Base64 / URL / Unicode 編解碼工具

完整支援 UTF-8 中文字元轉換，輕鬆在原始文字與各種常用編碼格式之間雙向切換。

常見編碼用途說明

  • Base64 編碼：將任意二進位或 UTF-8 文字轉換為純 ASCII 字元，常用於 HTTP Authorization 標頭、Data URI 或設定檔傳輸。
  • URL 編碼（Percent-encoding）：將網址中的中文、空白與特殊符號轉為 %XX 格式，確保瀏覽器與伺服器能正確傳遞查詢參數。
  • Unicode 跳脫字元：將非 ASCII 字元轉為 \uXXXX 形式，便於在 Java、JavaScript 或屬性檔中檢視與除錯。
